# 通知音效文件

本目录用于存放系统通知的音效文件。

## 所需音效文件

系统需要以下音效文件才能正常工作：

| 文件名              | 用途                   |
|-------------------|----------------------|
| notification.mp3  | 普通通知音效（新工单、状态变更、系统通知） |
| warning.mp3       | 警告通知音效               |
| error.mp3         | 错误通知音效               |

## 获取音效文件

您可以从以下免费音效网站获取合适的音效文件：

1. [Free Sound Effects](https://www.freesoundeffects.com/)
2. [Zapsplat](https://www.zapsplat.com/)
3. [Freesound](https://freesound.org/)
4. [SoundBible](https://soundbible.com/)

## 添加音效文件

1. 下载所需的音效文件
2. 将文件重命名为上述表格中指定的文件名
3. 复制到本目录中

## 注意事项

- 建议使用MP3格式的音效文件
- 音效文件大小不宜过大，建议控制在100KB以内
- 音效时长建议控制在1-2秒之间，不宜过长
- 建议选择清晰、简洁的音效，避免使用过于复杂或刺耳的音效
